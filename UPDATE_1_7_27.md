# Core v1.7.27 — график доступных магазинов

Заявки → График: при нескольких доступных магазинах добавлен фильтр «Все мои магазины» и выбор конкретной точки. Для роли с сетевым доступом надпись — «Все доступные магазины». Фильтрация локальная, без дополнительных запросов. Если доступен один магазин, отображается только он без лишнего выбора; если ни одного — сообщение о необходимости проверить привязку и права.

Серверное ограничение уже существовало и сохранено: orders.schedule_view с областью stores/own возвращает только магазины из привязок UserStore и активного сотрудника EmployeeStore, вместе с соответствующими правилами графика. Администратор и роли с областью network видят сеть. Добавлена передача data_scope в ответе для корректной подписи фильтра. Роли автоматически не перенастраиваются.

Проверьте Админ → Роли → Просмотр графика заявок: продавцу/управляющему задайте область закреплённых магазинов, если не требуется вся сеть. В Сотрудники проверьте связь с Telegram-пользователем и назначенные магазины. Учитываются также существующие прямые привязки пользователя к магазинам. Если у роли стоит «Вся сеть», вся сеть остаётся доступной.

Установка: обновите файлы, сохранив переменные окружения; перезапустите сервер и заново откройте MiniApp. /health: 1.7.27. Новых переменных окружения и миграции схемы нет. Подпись Пн–Вс и кнопка массового назначения во вкладке графика остаются удалёнными; редактор доступен через Админ.

Проверено автоматически: 43 JavaScript-теста, включая локальный выбор магазина и пустой список; 1 интеграционный серверный тест (SQLite) с несколькими сценариями — отсутствие привязок, привязка сотрудника, отсутствие чужих правил, администратор, явно разрешённый сетевой доступ. На рабочем сервере и в Telegram не проверено, установка не выполнена.
