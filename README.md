# Причал Core v1.7.8 — UI shell, виджеты и динамическая навигация

## Что нового в v1.7.8

- скрыта внутренняя строка с названием бота;
- глобальная верхняя навигация: Назад / Главная / Личная страница;
- нижнее меню строится по правам роли, выводится в два ряда и может сворачиваться;
- на пунктах меню появились динамические бейджи внимания;
- Главная стала персональным конструктором виджетов;
- виджеты можно добавлять, удалять, переставлять и менять размер S/M/L;
- доступность виджетов задаётся в Админ → Роли → Главная / Виджеты;
- темы: Системная, Mint, Ocean, Sand, Lavender, Graphite;
- сохранение персональной раскладки Главной в Neon.

Neon очищать не нужно. Новая таблица: `dashboard_preferences`.


Новая версия централизует все настройки Core в одном разделе «Админ-центр».

## Главное
- Инкассация, Наставничество, План/факт, старый Рейтинг и старые Рассылки скрыты из обычного меню по умолчанию. Их код и данные не удаляются.
- Локальные административные вкладки убраны из Заявок, Пересменок и Проверок.
- Новый Админ-центр: Роли / Пользователи / Справочники / Процессы / Контент / Telegram / Система / Журнал.
- Роли поддерживают уровни «Скрыт / Просмотр / Просмотр и изменение» и область «Свои / Закреплённые магазины / Вся сеть».
- Системные роли нельзя переименовывать/архивировать; администратор — неизменяемый superuser.
- Пользовательские роли можно создать пустыми или копированием существующей роли.
- У пользователя одна роль. Для совместимости с существующим backend у пользовательской роли хранится базовая системная роль.
- Есть просмотр эффективных прав роли и журнал изменений.
- Глобальные настройки и включение законсервированных модулей находятся в «Система».

## База
Neon очищать не нужно. Добавляются таблицы `role_definitions`, `role_permissions`, `admin_audit_log` и поле `users.role_key`.
