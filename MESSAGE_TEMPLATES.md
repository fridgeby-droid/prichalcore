# Конструктор Telegram-сообщений

Раздел: **Ещё → Telegram → Шаблоны**. Доступ: только роль `admin`.

## Поддерживаемые события

- Принятая заявка поставщику
- Принятая пересменка магазина
- Назначена смена
- Смена удалена
- Подмена / изменение смены
- Назначена задача
- Новый материал в Базе знаний
- Назначен тест

Каждый тип события имеет собственный набор допустимых переменных. Интерфейс показывает их рядом с редактором.

## Поведение

Сохранённый активный шаблон используется для всех новых отправок этого события. Если пользователь отключил кастомный шаблон, Core использует встроенный безопасный шаблон. Кнопка «Вернуть стандартный» полностью восстанавливает системные настройки.

Перед сохранением backend проверяет переменные, HTML-теги, ссылки и настройки медиа.
