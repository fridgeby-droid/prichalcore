# Причал Core v1.7.4 — Личная страница

Новый персональный кабинет открывается по круглому аватару на Главной.

## Вкладки
- **Профиль** — фото, ФИО, должность, статус, дата приёма, стаж, телефон, почта, Telegram ID, магазины и основной магазин.
- **Работа** — ближайшие и прошлые смены, активные и просроченные задачи, история задач и последние пересменки.
- **Обучение** — прогресс обязательных статей Базы знаний, назначенные тесты и история всех попыток с баллами.
- **Активность** — агрегированная история действий сотрудника в Core.
- **Настройки** — фото, телефон, почта, основной магазин и светлая/тёмная тема.

## Фото
Фото профиля загружается через Telegram. MiniApp создаёт запрос, пользователь отправляет фото в чат с ботом, а Core сохраняет Telegram `file_id`. Последнее фото используется как аватар.

## Будущие блоки
В профиле уже предусмотрены места для **Статистики** (Saby: выручка, средний чек, план/факт и др.) и **Достижений**.

## База данных
Для существующей PostgreSQL/Neon базы v1.7.4 автоматически добавляет в `employees`:
- `phone`
- `email`
- `primary_store_id`
- `app_theme`

Сброс базы не требуется.
