# Тестирование — Причал Core v1.7.3

## Поток сотрудника

`Назначен → В процессе → Сдан / Не сдан / Просрочен`.

После запуска теста навигация Core блокируется до отправки попытки или окончания серверного таймера. Принудительное закрытие Telegram не отменяет попытку.

## Поток руководителя

`Редактор → Банк вопросов → Назначение → Контроль → Разрешение повторной попытки`.

## Поддерживаемые вопросы

- один правильный ответ;
- несколько правильных ответов;
- текстовый ответ по списку допустимых формулировок;
- фото к вопросу через Telegram.

## База знаний

Тест можно связать со статьёй. Если включено автоматическое назначение, сотрудник получает тест после подтверждения ознакомления с актуальной редакцией статьи.

## AI

Endpoint-заглушка `/api/testing/ai-draft` зарезервирован под будущую генерацию черновика теста из статьи после подключения AI-агента.
