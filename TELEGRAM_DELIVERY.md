# Причал Core v1.7.5 — Telegram-маршрутизация и личные уведомления

## Что добавлено

### 1. Группы Telegram

Добавьте бота Причал Core в нужную рабочую Telegram-группу и отправьте в группе команду:

```text
/register
```

Команда доступна управляющему, ОД, руководителю и администратору, которые уже зарегистрированы в Core.
После команды группа появится в `Ещё → Telegram → Группы`.

### 2. Маршруты

В `Ещё → Telegram → Маршруты` можно связать:

- событие `Принятая заявка поставщику` → конкретный поставщик → Telegram-группа поставщика;
- событие `Принятая пересменка магазина` → конкретный магазин → Telegram-группа магазина.

Маршруты не зашиты в код: их можно менять через MiniApp.

### 3. Заявки

При переходе заявки из `Новая` в `Принята` Core:

1. сохраняет, кто и когда принял заявку;
2. формирует текст для поставщика;
3. отправляет его в группу, привязанную к поставщику;
4. сохраняет результат, Telegram `message_id` и ошибку, если она возникла;
5. защищает событие от случайной повторной автоматической отправки.

В карточке принятой заявки доступна ручная кнопка `Отправить повторно`.

### 4. Пересменки

После решения управляющего:

- `Принята` → отчёт отправляется в группу магазина;
- `Принята с замечаниями` → отчёт отправляется с явной отметкой о замечаниях;
- `Не принята` → в группу ничего не отправляется.

После текста Core повторно отправляет фотографии из пересменки с использованием Telegram `file_id`.
Для принятой пересменки доступна ручная повторная отправка.

### 5. Личные сообщения сотрудникам

Если карточка сотрудника связана с Telegram, Core может отправлять ему личные сообщения о событиях:

- назначена смена;
- смена удалена/изменена или назначена подмена;
- опубликован новый доступный материал Базы знаний;
- назначена новая задача;
- назначен тест.

К личному сообщению добавляется кнопка `Открыть Причал Core`.

Для массовой публикации статьи сообщения ставятся в очередь и отправляются планировщиком небольшими пакетами, чтобы публикация статьи не зависела от скорости Telegram.

### 6. Настройки и журнал

`Ещё → Telegram` содержит:

- `Группы` — зарегистрированные чаты и тест отправки;
- `Маршруты` — привязки поставщиков/магазинов;
- `Журнал` — успешные отправки и ошибки;
- `Личные` — включение/отключение типов личных сообщений для конкретного сотрудника.

### 7. Ограничение Telegram

Бот не может первым начать личный диалог с человеком. Для личных уведомлений сотрудник должен хотя бы один раз открыть/запустить бота Причал Core. Ошибки доставки не ломают основной бизнес-процесс и сохраняются в журнале.

## Новые таблицы

```text
telegram_destinations
telegram_routes
telegram_delivery_logs
employee_notification_preferences
```

Также в `orders` добавляются:

```text
accepted_by
accepted_at
```

Neon очищать не нужно: недостающие поля добавляются автоматически при старте.

## v1.7.6 — шаблоны сообщений

Администратору доступна вкладка **Telegram → Шаблоны**. Для каждого текущего автоматического события можно изменить текст, форматирование, переменные, кнопку и (для пересменки) правила отправки фото. Есть предпросмотр, тестовая отправка и возврат к системному шаблону.

Таблица: `telegram_message_templates`. При первом запуске стандартные шаблоны создаются автоматически; существующая маршрутизация и журнал доставки сохраняются.
