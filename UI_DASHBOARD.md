# UI v1.7.9

## Навигационные бейджи
Бейдж — индикатор необработанных объектов, а не исторический счётчик. Цвет наследуется от активной темы.

### Текущая логика
- Заявки: `new`, `skipped`.
- Задачи: `new`.
- Тесты: `assigned`.
- Пересменки: на проверке у управляющего; возвращённые — у исполнителя.
- База знаний: обязательные непрочитанные материалы.
- Проверки: магазины с невыполненной недельной нормой.
- Telegram: ошибки доставки.

Бейджи обновляются после любых мутаций API, при возврате в MiniApp и каждые 30 секунд.

## Dock
В раскрытом виде показывает двухрядное динамическое меню. При сворачивании сетка плавно уходит вниз с fade/scale, остаётся ручка раскрытия.
