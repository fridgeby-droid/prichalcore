# UI v1.7.8

## Навигация
Нижнее меню формируется из доступных модулей роли. Модули со всеми правами `hidden` не показываются. Меню раскладывается максимум в 5 колонок и 2 ряда. Кнопка-стрелка над меню сворачивает его до компактной ручки; состояние хранится локально на устройстве.

## Бейджи
Core показывает красный счётчик только для объектов, требующих внимания: новые заявки, задачи, пересменки, обязательные статьи, тесты, контроль проверок и ошибки Telegram.

## Главная
`GET /api/dashboard/ui` отдаёт каталог доступных по роли виджетов, персональную раскладку, значения и бейджи. `PUT /api/dashboard/layout` сохраняет порядок и размеры.

Размеры: S — счётчик, M — карточка, L — широкий блок.

## Темы
Поддерживаются `system`, `mint`, `ocean`, `sand`, `lavender`, `graphite`. Старые `light` и `dark` продолжают корректно открываться и отображаются как Mint/Graphite.
